# 测试计划：「伴读 / ReadMate」MVP

> 版本：v1.0 ｜ 制定：2026-08-30 ｜ 依据：`01-需求分析/需求规格说明书-SRS.md` ｜ 状态：已执行完毕（见测试报告）

## 1. 测试范围

| 层级 | 范围 | 工具 |
|---|---|---|
| 单元测试（后端） | EPUB 解析 / 导入去重 / API 校验 / 备份往返 | pytest 27 项 |
| 单元测试（前端 TS） | Provider 协议转换与错误映射 / Context 组装预算 | vitest 12 项 |
| E2E（Electron） | 阅读器全流程（书架→详情→渲染→导航→设置→高亮） | Playwright 11 断言 |
| E2E（真实 API） | AI 配置/连接/流式/调用记录 ｜ 访谈→反思→Journal 全流程 | Playwright 16 断言 |
| 手工验收 | 真实书籍全流程走查（用户） | 验收清单 |

## 2. 测试环境

- Windows 11 / Electron 33（WebView2）/ React 19 / Vite 6
- 后端：Python 3.13 + FastAPI + SQLite（本地 127.0.0.1:8000）
- AI：真实厂商 API（OpenCode 网关，deepseek-v4-pro）
- 测试数据：自动生成的最小 EPUB（3 章标准 + 无目录 + 脏 HTML 三种）

## 3. 测试策略（按测试金字塔）

- **单元测试**：核心逻辑（解析/协议/组装）全覆盖，mock 外部依赖
- **集成/E2E**：Playwright 驱动真实 Electron，走用户真实操作路径
- **AI 相关**：协议层用 mock（不烧 token）；流程层用真实 API（验证 Prompt 真实效果）

## 5. 执行命令

```bash
cd backend && .venv/Scripts/python -m pytest          # 27 项
cd frontend && npx vitest run                         # 12 项
cd frontend && node e2e/reader.cjs                    # 阅读器 11 断言
cd frontend && node e2e/ai.cjs                        # AI 6 断言（需 API Key 环境变量）
cd frontend && node e2e/reflect.cjs                   # 伴读闭环 10 断言（真实 API）
```
